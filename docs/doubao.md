# 在豆包工作中使用

## 直接玩同款

正式试玩链接：https://xshuiai.github.io/shui-party-box/

打开该链接即可；Skill 是制作说明，运行游戏不要求先安装 Skill。若豆包不能内嵌打开，复制链接到手机浏览器。

## 复制这段给豆包

```text
请打开并试玩这个页面：https://xshuiai.github.io/shui-party-box/

源码与 Skill 在：https://github.com/XshuiAi/shui-party-box

我想在手机上玩 Sherry 小水的同款聚会游戏，请优先运行仓库现有成品，不要重新生成设计。

1. 先打开上述试玩链接；不要重新生成设计，也不要把 GitHub 代码页或 localhost 当成试玩链接。
2. 如果当前环境支持从 GitHub 导入 Skill，读取根目录 SKILL.md，按实际支持的方式导入；若不支持，请直接试玩，不要声称安装成功。
3. 使用默认紫色版，保留七个游戏、自选和转盘、2–5 人、轮流操作、私密看词、计分与音乐开关。不添加换肤按钮、宣传口号或付费依赖。
4. 音乐按第一首→第二首→第三首顺序循环；不要自行下载或替换音乐。
5. 完成后检查首页、选游戏、7 个游戏的一轮操作、再来一轮、返回、手机窄屏、音乐开关与轮播。保留作者和许可证，不擅自覆盖或重新公开部署新的作品。
```

## 只改自己的题库

```text
基于 https://github.com/XshuiAi/shui-party-box 的现有紫色成品，把真心话和 5 秒说三个改成适合我和 4 位朋友的题目。其余游戏、UI、人数、计分、按住看词和音乐逻辑不变。保留作者署名和许可；另存新项目，给我可用的预览或完整文件夹。
```

## 手机测试

1. 打开真实 HTTPS 页面，确认图片和按钮加载完成。
2. 选 2、3、4、5 人；低于 4 人时不能进入谁是卧底。
3. 自选一次，再转盘选一次；完成一轮骰子、猜词或投票。
4. 按住看词，松手应隐藏；切到后台不要留下词语。
5. 主动点声音后播放，测试顺序轮播、关闭与返回后台。

豆包账号的 Skill 入口、网页执行和分享能力以实际界面为准。本项目未代替你完成豆包内安装测试。
